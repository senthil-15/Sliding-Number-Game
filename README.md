# Sliding-Number-Game
A game created using C language, which requires the user to slide the numbers to correct position using arrow keys.
The .exe file can't run natively in modern Windows OS like Windows 10/11. You need to use an emulator like 'DOSBox' to run this 'NUMGAME.EXE' file. Download 'DOSBox', mount the location of the .exe file with a drive. Switch to that drive and run the file.
